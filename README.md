# DocStatsAI

**Website:** [https://docstatsai.by/](https://docstatsai.by/)
**StoryBook:** [https://maryanzh.github.io/Doc_Stats_AI/?path=/story/layout-header--default]

## Overview

DocStatsAI is a web application built with **Angular 22+** using **Signals** for reactive state management.  
It provides intelligent document statistics and visualization tools powered by AI.

The project includes both **frontend** and **backend** components:

- **Frontend:** Angular 22+ (this repository)
- **Backend:** [AI-Workspace-backend](https://github.com/MaryAnzh/AI-Workspace-backend)

## Features
